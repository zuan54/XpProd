# XPprod / XPPROD — сайт GitHub Pages

**Рабочий URL:** https://zuan54.github.io/XpProd/

## В этой сборке

- Иконка сайта (favicon/аватар) сделана из присланной картинки XP: добавлены PNG для вкладки и телефона, ICO для браузеров и иконки приложения в webmanifest.
- Title, описание, Open Graph, canonical и структурированные данные уточнены под бренд XPprod/XPPROD и реальные направления в Екатеринбурге.
- На странице естественно описаны услуги: видеосъёмка для бизнеса, рекламные ролики, Reels и видео для соцсетей, монтаж.
- JSON-LD содержит только сведения, подтверждённые содержимым сайта: город, телефон, Telegram и направления услуг.
- `robots.txt` указывает на корректный `sitemap.xml`.
- Vimeo-запросы отложены до нажатия на видео; изображения оптимизированы и находятся в `assets/`.
- В карточках снова есть превью всех 31 Vimeo-ролика: это локальные WebP в `assets/thumbs/`, они загружаются лениво; Vimeo-плеер не стартует до нажатия.


## Android и мобильная плавность

- На телефонах отключена полноэкранная движущаяся картинка и изменение её позиции на каждом прокручивании; вместо неё используется статичный XP-синий градиент в hero и светлый фон портфолио.
- Отключены непрерывные декоративные анимации, blur/backdrop-filter и тяжёлые hover/transition-эффекты на сенсорных устройствах; карточки и тени упрощены.
- Превью не удалены: все 31 WebP остаются локально в `assets/thumbs/`. Браузер получает `src` картинки только когда карточка приближается к видимой области; Vimeo iframe по-прежнему появляется только после нажатия.
- SEO, favicon, телефон/TG, видео и настольная версия сохранены.

## Обновить репозиторий `zuan54/XpProd`

1. Распакуйте архив целиком.
2. На GitHub откройте репозиторий → **Add file → Upload files**.
3. Загрузите с заменой файлы в корне и папку `assets` целиком. В GitHub пути к изображениям должны начинаться с `assets/`.
4. Нажмите **Commit changes** в `main`, дождитесь зелёного статуса во вкладке **Actions**.
5. Проверьте `https://zuan54.github.io/XpProd/` и `https://zuan54.github.io/XpProd/sitemap.xml`.
6. Чтобы увидеть новую иконку, обновите сайт без кэша или откройте в приватном окне: браузер может хранить старый favicon.

## Попросить Google и Яндекс обновить страницу

**Google Search Console:** выберите URL Inspection для `https://zuan54.github.io/XpProd/` → **Request indexing**; в разделе Sitemaps отправьте `https://zuan54.github.io/XpProd/sitemap.xml`. Затем проверьте выбранный Google canonical.

**Яндекс Вебмастер:** добавьте/подтвердите URL проекта, отправьте тот же sitemap и посмотрите диагностику обхода. Везде сохраняйте путь `/XpProd/`.

## Честно о тегах и сроках

`meta keywords` добавлен как справочный список, но Google его не использует для ранжирования. Поиску помогают точные title и описание, полезный видимый текст, единый canonical, sitemap, ссылки/упоминания и подтверждённые контакты. Список целевых тем: XPprod, XPPROD, видеограф в Екатеринбурге, видеосъёмка Екатеринбург, снять видео в Екатеринбурге, видеосъёмка для бизнеса, видеопродакшн/видеопродакшен Екатеринбург, рекламный ролик, съёмка Reels, видео для соцсетей, монтаж видео. Темы отражены на странице естественно — не скрытым текстом.

Невозможно гарантировать мгновенный показ или первое место. `XP` — слишком общий запрос; `XPPROD` точнее, но поисковику нужно время связать бренд с сайтом. Запрос на индексацию не гарантирует включение в индекс. Следите за статусом в Search Console и Вебмастере; улучшайте узнаваемость бренда единым написанием XPprod/XPPROD, публикуйте реальные кейсы и получайте настоящие ссылки/упоминания. Не добавляйте выдуманные отзывы или контакты.
